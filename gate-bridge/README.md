# 🌉 GateBridge v1.0.0 — puerta del 2FA

El menú 2FA solo existe con el permiso `skylith.2fa.required`.
Como xLogin **congela** a los no logeados, moverse = logeado:
al caminar 2 bloques se otorga el permiso (y el menú aparece);
al salir se retira. Sin permiso no hay menú antes del login.

Requiere quitar el permiso de los grupos (solo por usuario).
